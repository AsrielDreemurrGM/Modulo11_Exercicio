<h1>Responsive Computer Store</h1>

    Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
    A fictional responsive computer store website built with <strong>HTML5</strong> and
    <strong>CSS</strong>, showcasing the use of responsive design techniques for different
    screen sizes.
</p>
<p>
    🔗 Live Demo: <a href="https://responsive-computer-store-asrdrgm.vercel.app/" target="_blank">View on Vercel</a>
</p>
<h2>About</h2>
<p>
    The project was created as a practice exercise in building a simple e-commerce style
    layout while applying responsive design. It features a homepage with a store description
    and a product catalog section. The layout adapts seamlessly across desktop, tablet,
    and mobile devices.
</p>
<h2>Technologies Used</h2>
<ul>
    <li>HTML5</li>
    <li>CSS</li>
    <li>Responsive Design</li>
</ul>
<h2>Features</h2>
<ul>
    <li>Responsive layout for desktop, tablet, and mobile;</li>
    <li>Navigation menu with internal section links;</li>
    <li>Product cards with images, titles, and descriptions;</li>
    <li>Hover effect on buttons for better interactivity;</li>
    <li>Clean and simple e-commerce inspired design.</li>
</ul>
<h2>Commit Highlights</h2>

</ul>
<h2>Notes</h2>
<p>
    This project demonstrates the fundamentals of responsive web design,
