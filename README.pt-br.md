<h1>Loja de Informática Responsiva</h1>
<p>
    This README is also available in <a href="./README.md">English</a>.
</p>
<p>
    Um site fictício de loja de informática responsiva desenvolvido com <strong>HTML5</strong> e
    <strong>CSS</strong>, aplicando técnicas de design responsivo para diferentes tamanhos de tela.
</p>
<p>
    🔗 Live Demo: <a href="https://responsive-computer-store-asrdrgm.vercel.app/" target="_blank">Ver no Vercel</a>
</p>
<h2>Sobre</h2>
<p>
    O projeto foi criado como um exercício prático para construir um layout simples no estilo
    e-commerce enquanto aplicava conceitos de design responsivo. Ele apresenta uma página inicial
    com descrição da loja e uma seção de catálogo de produtos. O layout adapta-se de forma fluida
    para desktops, tablets e dispositivos móveis.
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
    <li>HTML5</li>
    <li>CSS</li>
    <li>Design Responsivo</li>
</ul>
<h2>Funcionalidades</h2>
<ul>
    <li>Layout responsivo para desktop, tablet e mobile;</li>
    <li>Menu de navegação com links internos para seções;</li>
    <li>Cards de produtos com imagens, títulos e descrições;</li>
    <li>Efeito de hover em botões para melhor interatividade;</li>
    <li>Design limpo e simples inspirado em e-commerce.</li>
</ul>
<h2>Destaques dos Commits</h2>
<ul>
    <li>Criada a estrutura inicial em HTML e folha de estilos CSS;</li>
    <li>Implementado design responsivo com media queries;</li>
    <li>Finalizado layout para desktop, tablet e mobile;</li>
    <li>Ajustadas imagens dos produtos e melhorada a qualidade geral;</li>
    <li>Estilizado navegação, cabeçalhos e seções de produtos;</li>
    <li>Melhorados espaçamentos, margens e legibilidade do texto;</li>
</ul>
<h2>Notas</h2>
<p>
    Este projeto demonstra os fundamentos do design responsivo,
    com foco na adaptação do layout e em uma experiência de uso agradável.
    Ele serve como um template para sites simples no estilo e-commerce.
</p>
